# Quiet Luxury 〜次世代型ネイルスクール〜 LP

30〜50代の女性ネイリスト向け・自宅サロン開業スクールのランディングページ。単一HTML（CSS・JSインライン、ライブラリはCDN）。

## 公開（GitHub Pages）

`main` ブランチのルートを GitHub Pages で公開すると `index.html` がそのまま表示されます。
GitHub Pages は本物のHTTPSホストなので、CDN（GSAP／Lenis／Splide）と Google Fonts が読み込まれ、**アニメーションもフォントも本来の状態で動きます**（Artifactプレビューと違い制限なし）。

## 差し替えが必要な箇所

HTML内に `要確認` / `要差し替え` バッジが残っています（実績数値・受講生の声・税表記・分割払い可否など）。公開前に差し替えてください。
